# NewTube — гібридний плеєр із settings-панеллю (дизайн)

> Дата: 2026-11-28. Вихідні дані: вибір варіанту C у Brainstorm Companion, скріншоти плеєрів YouTube і GreenTuber з пристрою, логи пристрою з HTTP 403.

## 1. Намір і чому

Користувач хоче, щоб плеєр NewTube виглядав і відчувався максимально схоже на YouTube та GreenTuber, і скаржиться на дві речі:
1. У повноекранному режимі свайп плеєра його згортає — через це неможливо протестувати тапи по екрану та жести гучності/яскравості.
2. При завантаженні деяких відео з'являється помилка.

Додатково: усі написи й функції, які зараз висять над плеєром (`Аудіо`, `Вписати`, `Auto`, PiP), мають переїхати в налаштування.

## 2. Що побачено на пристрої

**YouTube (video, не fullscreen):** верхній рядок `⌄ · play toggle · cast · CC · ⚙`;center `⏮ ⏸ ⏭`; низ `0:27 / 3:33` + червоний прогрес + `⛶`. Settings — компактний bottom sheet із drag handle: `Якість — Авто (480p) ›`, `Швидкість від… — 1x ›`, `Субтитри — Англійська ›`, `Заблокувати екран`, `У дорозі (Premium)`, `Більше ›`.

**GreenTuber:** рядок плеєра `X · 360p · 1x · ⚙`, center `⏸`, низ `2:59:58` + червоний прогрес + `НАЖИВО` + `⛶`. Settings-панель із X і 12 рядками: `Екран — Збільшити`, `Підписи — Немає субтитрів`, `Повторіть` (toggle), `Таймер`, `Звук` (toggle), `Жест яскравості` (toggle), `Жест збільшення` (toggle), `Швидкість під час утримання — 3X`, `Надавати перевагу оригінальній аудіодоріжці` (toggle), `Мова контента за замовчуванням — Система за замовчуванням`, `Кастинг`, `Браузер`.

**NewTube зараз:** Media3 `PlayerView` з `useController=true` малює стандартні контроли; поверх них у `TopEnd` висить Compose-рядок `Аудіо / Вписати / Auto / PiP / Fullscreen`. Повноекранний свайп іде через `PlayerGestures.kt` (лише гучність/яскравість, `consume()`), а `shouldMinimize()` явно має `!isFullscreen`. Помилка в логах: `ExoPlayerImplInternal ... InvalidResponseCodeException: Response code: 403` з `DefaultHttpDataSource.open` → `Playback failed (ERROR_CODE_IO_BAD_HTTP_STATUS)`.

## 3. Цілі / не-цілі / анти-цілі

**Цілі**
- G1. Гібрид C: власні Compose-бари (як YouTube) + bottom-sheet налаштувань (як GreenTuber).
- G2. На плеєрі лишаються тільки: назад/закрити, play/pause, ±10 с, прогрес і час, повноекран, ⚙. Усі текст-btn-и переїжджають у settings.
- G3. У fullscreen жоден свайп не згортає плеєр; жести гучності/яскравості працюють у середині екрана, системні краї не перехоплюються; BackHandler виходить із fullscreen, а не з екрана.
- G4. Відео відтворюється: виправити HTTP 403 для прямих `googlevideo.com` URL.
- G5. Ukrainian UI у всіх нових рядках і помилках; помилка має містити зрозуміле повідомлення й Retry.

**Не-цілі**
- Не додаємо реальні субтитри, cast, браузер, таймер — ці рядки можуть бути присутніми, але позначені як недоступні (`Недоступно`) або відкриватиCorresponding системні можливості.
- Не змінюємо Shorts-плеєр (він має окремий контролер і `useController=false`), окрім спільних утиліт жестів.
- Не міняємо джерело даних/кешування.

**Анти-цілі**
- Не повертати `clickable` overlay поверх усього плеєра: він ковтає тапи контролерів.
- Не викликати `onMinimize` з будь-якого fullscreen-шляху.
- Не хардкодити секрети/заголовки з токенами.

## 4. Підходи

- **A. Тюнинг Media3** — мінімально, але вигляд лишається стандартним і неможливо прибрати написи з-над плеєра. Відхилено.
- **B. Повний кастомний контролер** — найточніше, але дуже великий diff і ризик зламати PiP/Shorts.
- **C. Гібрид (ОБРАНО)** — власні бари + settings sheet; контроли лишаються тонкими, але вигляд керований.

## 5. Рішення, зафіксовані в дизайні

### 5.1 Компонування плеєра
- `WatchScreen` лишається власником стану `isFullscreen` / `isMinimized` / `isPiP`.
- `VideoPlayer` припиняє покладатися на Media3-контролер для видимих елементів: `useController=false` у звичайному й fullscreen режимах (PiP уже так). Замість цього нові Composables:
  - `PlayerTopBar` — назад/закрити (у fullscreen — вийти), поточний стан якості компактно, ⚙, (за потреби CC/cast);
  - `PlayerCenterControls` — ⏮ / play-pause / ⏭ з double-tap seek через існуючий `PlayerGestureOverlay`;
  - `PlayerBottomBar` — `current / duration`, `Slider`, LIVE-мітка, повноекран.
- Automatyczne приховування контолів через 3 с після тапу (як у YouTube).

### 5.2 Settings-панель
- `PlayerSettingsSheet` — `ModalBottomSheet` із drag handle й X, прокручуваний, із групами:
  1. **Відтворення:** Якість ( Авто / ≤Np ), Швидкість (0.5…3x), Аудіодоріжка, Повторювати (toggle), Швидкість під час утримання (3x).
  2. **Зображення:** Екран (Вписати/Заповнити/Обрізати), Жест яскравості (Ліва/Права/Вимкнено), Жест збільшення (toggle), Блокування екрана (недоступно).
  3. **Інше:** Таймер (недоступно), Мова контента (Система/…), Субтитри (Немає субтитрів), Кастинг (недоступно), Браузер (недоступно).
- Поточне значення виділено акцентним кольором, як у GreenTuber; рядок-значення відкриває вкладений список або перемикає toggle.
- Усі підписи й повідомлення про помилки — українською.

### 5.3 Жести та fullscreen
- `PlayerGestures.kt`: у fullscreen прибираємо будь-який шлях до `onMinimize`; `shouldMinimize()` залишається тільки для non-fullscreen і лише якщо gesture починається не в системних краях.
- Додаємо `BackHandler(enabled = isFullscreen) { isFullscreen = false }`.
- Для volume/brightness: початкова точка ≥48 dp від верхньої/нижньої межі, а системні edge-свайпи не споживаємо.
- `WindowInsetsControllerCompat` у fullscreen: `hide(WindowInsetsCompat.Type.systemBars())`, без `BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`, щоб край не показував системні панелі й не запускав back.

### 5.4 HTTP 403
- Замінити `DefaultDataSource.Factory` у Watch (і, якщо потрібно, у Shorts) на `OkHttpDataSource.Factory` з тим самим `OkHttpClient`, що й InnerTube, і заголовками `User-Agent` клієнта, `Referer: https://www.youtube.com/`, `Origin: https://www.youtube.com` (без токенів/секретів).
- Додати retry зі свіжим `player`-запитом при `403` (підписані URL мають короткий TTL) і Ukrainian помилку з Retry.
- Додати тест/перевірку на пристрої: відтворення того ж відео, що зараз падає.

## 6. Що лишається реалізатору
- Точний набір іконок (Material Icons) і розміри рядків.
- Чи робити CC/cast рядки активними чи `Недоступно` — рішення реалізатора в межах non-goals.
- Деталі анімації bottom sheet і timeout автоматичного приховування контролів (рекомендовано 3 с).
